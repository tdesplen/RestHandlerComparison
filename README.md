I performed an experiment to explore how different Claude's responses would be for a typical short prompt to create a REST GET handler in Java using the Spring framework. 

Any engineer that deals with systems that have Company and User objects (so every business system basically) would reasonably have written something similar to get started.

Experiment: 
I asked Claude's Sonnet 4.6 to build me the REST handler that is defined in prompt.txt
I asked this five times in a row, each time in a brand new chat window without 'memory' turned on.

Result:
Five different responses. Each one is contained in a separate "ResponseX.java" file under the 'src' folder.
